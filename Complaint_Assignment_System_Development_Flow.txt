COMPLAINT ASSIGNMENT SYSTEM
Complete Development Flow
========================================

PROJECT TYPE
-------------
Small console-based project using:
- Python
- MySQL
- mysql-connector-python
- Virtual Environment (venv)

No Flask, Django, HTML, CSS, JavaScript, or SQLAlchemy.


FINAL BUSINESS FLOW
-------------------
CUSTOMER
   |
   | Raise Complaint
   v
DATABASE
   |
   v
ADMIN
   |
   | Assign Complaint
   v
EMPLOYEE
   |
   | Work on Complaint
   | Complete Complaint
   v
CUSTOMER
   |
   | Give Feedback
   v
DATABASE
   |
   +-------------> ADMIN can view feedback
   |
   +-------------> EMPLOYEE can view feedback

PHASE 4 - CUSTOMER MODULE
========================================

9. Customer registration

Customer enters:
- Name
- Email
- Phone

Save customer into the customer table.

10. Customer login

Customer enters email.

Python checks the customer table.

11. Customer menu

1. Register Complaint
2. Check Complaint Status
3. Complaint History
4. Give Feedback
5. Exit


========================================
PHASE 5 - COMPLAINT MODULE
========================================

12. Customer raises complaint

Customer enters:
- Machine model
- Machine number
- Problem
- Priority

Save complaint with:
- complaint_id
- customer_id
- machine_model
- machine_number
- problem
- priority
- status
- created_at

Initial status:

OPEN


========================================
PHASE 6 - CUSTOMER COMPLAINT HISTORY
========================================

13. Customer views complaint history.

Customer should see only their own complaints.

Display:
- Complaint ID
- Machine
- Problem
- Priority
- Status
- Created Date


========================================
PHASE 7 - ADMIN MODULE
========================================

14. Admin login.

15. Admin menu

1. View New Complaints
2. Assign Complaint
3. View All Complaints
4. View Feedback
5. Exit


========================================
PHASE 8 - EMPLOYEE MANAGEMENT
========================================

16. Admin adds employees.

Employee information:
- Employee name
- Email
- Phone

Save into employee table.


========================================
PHASE 9 - ADMIN VIEWS COMPLAINTS
========================================

17. Admin views new/open complaints.

Example:

Complaint ID
Customer
Problem
Priority
Status

Admin selects a complaint to assign.


========================================
PHASE 10 - COMPLAINT ASSIGNMENT
========================================

18. Admin assigns an employee.

Admin selects:
- Complaint ID
- Employee ID

Create a record in assignment table.

Then update complaint status:

OPEN -> ASSIGNED


========================================
PHASE 11 - EMPLOYEE MODULE
========================================

19. Employee login.

20. Employee menu

1. My Assigned Complaints
2. Start Complaint
3. Complete Complaint
4. View Feedback
5. Exit


========================================
PHASE 12 - EMPLOYEE ASSIGNED COMPLAINTS
========================================

21. Employee views only complaints assigned to them.

Relationship:

employee
   |
   v
assignment
   |
   v
complaint


========================================
PHASE 13 - START SERVICE
========================================

22. Employee selects an assigned complaint.

Update status:

ASSIGNED -> IN_PROGRESS


========================================
PHASE 14 - COMPLETE SERVICE
========================================

23. Employee completes the work.

Update status:

IN_PROGRESS -> COMPLETED


========================================
PHASE 15 - CUSTOMER CHECKS STATUS
========================================

24. Customer checks complaint status.

Customer can see:

- Complaint ID
- Problem
- Employee
- Status


========================================
PHASE 16 - CUSTOMER FEEDBACK
========================================

25. Customer gives feedback after complaint is COMPLETED.

Customer enters:
- Rating
- Comments

Save into feedback table.


========================================
PHASE 17 - ADMIN FEEDBACK
========================================

26. Admin views feedback.

Admin can see:
- Complaint
- Customer
- Employee
- Rating
- Comments
- Date


========================================
PHASE 18 - EMPLOYEE FEEDBACK
========================================

27. Employee views feedback.

Employee should see feedback only for complaints assigned
to that employee.
